# Vendored third-party skills — provenance manifest

Before any external skill is vendored or forked here, its text is read for steps that send code or project data to an external service (register, publish, or telemetry steps); such steps are scoped to public or OSS work only, or the skill is excluded (BUG-022). Never edit verbatim vendored content in place — fork under a new name with upstream attribution and license beside `SKILL.md`. A path in a Source/Derived-from cell written `<upstream>/…` names the path in the upstream repository, not in this checkout, and a Pin is recorded only after `git archive <pin> <path> | tar -x` into scratch and `diff -r` against the directory (`BUG-111`; `TestVendoredRowsCarryAPin` checks repository and commit/digest pin).
