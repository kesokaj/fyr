# Screenshot index

161 reference renders of the theme simulator at 1280×800 (desktop) and 400×820 (phone), with the real typefaces loaded. File names are `<theme>-<view>.png`, `detail-<theme>-<part>.png`, `mobile-<theme>-<view>.png`, `sheet-<theme>.png` (all four views on one image) and a few special ones.

## Start here

- `sheet-all-desks.png` — all six themes, Desk view, on one image
- `anti-pattern-generic-vs-broadsheet.png` — the generic generated look (left) next to Broadsheet (right); `anti-pattern-generic-desk.png` is the left half at full size
- `sheet-<theme>.png` — one image per theme with Desk, Brief, Components and Tokens

## Special

- `overlay-broadsheet-desk.png`, `overlay-airy-desk.png`, `overlay-instrument-desk.png` — the white-space readout with "show ink" on: tinted boxes are what counts as ink
- `spacing-airy-x07.png`, `spacing-airy-x10.png`, `spacing-airy-x16.png` — Airy at spacing multipliers 0.7, 1.0 and 1.6
- `mobile-broadsheet-brief.png`, `mobile-airy-components.png` — phone width, other views
