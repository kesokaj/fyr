- F5 The GitHub rename: `gh` API reads and `git` remotes follow the redirect until a repository named `styrman-harness` is created again under the account — the plan forbids that, in `deploy/remote.md`; a checkout place's `origin` is changed by hand (`git remote set-url`, § Crossing to fyr), never by `update` (D16).
