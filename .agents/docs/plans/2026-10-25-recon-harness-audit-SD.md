# Recon — harness-audit SD: search, memory, dream (2026-10-25, commit c4885ae)

## Status: COMPLETE

Read-only; no `fyr`, `go` or `sh-agent` run. 21 of 30 tool calls used. Baseline outputs read from `.agents/scratch/harness-audit/2026-10-25/`.

## Summary

The three packages hold up against the asks. Every git call into a project goes through `trail.Command`. Model output is fenced as data, the model has no tool grants, and its output lands only in `~/.config/fyr/proposals/` for the operator. The dry-run shows the cap works. The real gaps are: (1) any clone with `.agents/docs` that is searched once is registered and goes nightly to the model (a security judgement for the operator); (2) the search spec's measured numbers and one exit code are stale or contradictory; (3) the project name reaches the prompt and the proposals header without the one-line fold every other field gets. `ReplaceOldTimer` and its `on()` probe are sound for the paths I could read; the macOS branch was not run.

## Refuted

- "A model answer can run a command": the call is `agy --mode plan` with a private HOME and `settings.json` granting nothing (`run.go` `agyHome`); `answer()` returns no answer on any tool step or denied action. Output goes to files under `~/.config/fyr/proposals/` at mode 0600.
- "A model-chosen skill name or path can write outside the proposals dir": `skillName` regexp `^[a-z0-9][a-z0-9-]{0,63}$` gates drafts; `unique` joins fixed prefixes; `File:` is only printed (folded by `o.line`).
- "A repository's git config can make search, memory or dream run a program": covered by `trail.Command` (fsmonitor, signature, lazy fetch); partial clones guarded. Inherited `GIT_*` and `PATH` come from the operator's environment, not the repository. A symlinked `.agents`, `.agents/scratch`, `.agents/memory` and `MEMORY.md` are all refused.
- "A scratch home shares a timer with the real one": `namesFor` hashes any home that is not the account's; `TestReplaceOldTimer` covers the other-home case (timer_test.go:536). The dream's agy login is read from the real `$HOME` by design (`run.go` `agyHome`, the comment states it).
- "`ReplaceOldTimer` can leave no timer": new unit is written and started before `old.remove()`; a refused install keeps the old one with the error (`timer.go:365-367`). `on()` treats a missing manager or a failed probe as on. The one gap is that both fire in 03:00 if the removal fails; the error is returned.
